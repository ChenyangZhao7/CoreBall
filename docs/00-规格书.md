# CoreBall Bot — 项目开发规格书 v0.1

> 一个灵魂、任意身体：核心球机器人平台

## 1. 一句话定义

一个球形的 AI 伴侣机器人"核心"（人格/记忆/感知/对话），可对接多种移动载体（桌面轨道、缆绳飞猫、机械臂、轮式底盘、四足），在工位、房间、随身等场景连续陪伴。

## 2. 背景与动机

- 灵感源自童年 IP「超能 NoNo」（赛尔号）的意象，但外观与设定完全原创，规避淘米版权
- 产品哲学：人类幻想中的陪伴小精灵都"漂浮"在空中；本项目的悬浮感由运动实现，不由反重力实现
- 核心理念：语言只占情感交互的 30%，行为与姿态占 70%——产品通过"移动即表达"建立生命感
- 参考公司：Skyris（宇灵无限，会飞的陪伴机器人）——本项目是其桌面/工位场景的互补形态

## 3. 产品形态定义

### 3.1 核心球（Core）
- 直径 12–15cm 球形本体，重量目标 ≤ 500g（载体承载上限）
- 上下半球分件外壳，环绕灯带槽作为唯一"五官"（发光材质表情：豆豆眼/眯眼/爱心眼）
- 内置：麦克风、摄像头（前置）、小喇叭、主控板、对接机构（机械 + 供电 + 数据三合一接口）
- 内部结构：环形支架 + 对接环（所有载体共用同一接口标准）
- 情绪驱动行为：安静陪伴 / 主动靠近 / 回避躲藏，行为由感知→情绪→动作链生成

### 3.2 载体家族（Carrier）
| 载体 | 运动维度 | 场景 | 优先级 |
|---|---|---|---|
| 桌面轨道 | 二维 | 工位 | P0 |
| 缆绳飞猫 | 三维 | 房间上空（需避障） | P1 |
| 机械臂末端 | 定点作业 | 工位精细操作 | P2 |
| 轮式底盘 | 二维地面 | 室内地面 | P2 |
| 四足 | 全地形 | 户外/陪伴 | P3 |

### 3.3 交互语义（移动即表达）
- 停在角落 = 待命；滑到手边 = 有事提醒；转到面前正对 = 需要注意力
- 用户难过 → 缓慢靠近贴贴；检测到争吵 → 退避远处
- 静默优先：存在感靠姿态与灯光，不靠语音轰炸

## 4. 系统架构

```
[载体层] 轨道滑台 / 缆绳绞盘 / 轮式底盘 / 四足 / 机械臂
   ↑ 统一对接接口（机械 + 电源 + 数据总线）
[核心球] 感知(麦+摄像) → 情绪状态机 → 行为生成 → 表情/语音
   ↑
[服务层] ASR → LLM → TTS；长期记忆；插件系统（"芯片"）
```

- 核心球为常驻身份载体：记忆与人格跟随球走，换载体不换灵魂
- 载体只负责执行运动指令，感知与人格始终收敛于核心球

## 5. MVP 范围（第一阶段，唯一交付目标）

**核心球 + 桌面轨道载体**，完成以下闭环：
1. 球放置在轨道滑车托盘上（磁吸固定，可随手取下随身带走）
2. 三个预设位置走位：角落待命 → 滑到手边 → 转到用户面前
3. 到位后灯带表情亮起 + 语音打招呼
4. 语音对话：唤醒 → ASR → LLM → TTS
5. 取放检测：球被拿起 → 进入随身模式（降低音量、停止走位）；放回 → 恢复

**明确不做**：缆绳飞猫避障、机械臂、四足、多房间、商业化功能

## 6. 技术栈（MVP）

- 建模/渲染：Blender（外壳、载体、爆炸图、概念片素材）
- 主控：ESP32（走位/灯带/传感器）；语音链路可先用树莓派/PC 端跑通
- 轨道：V 型铝型材 + GT2 同步带 + NEMA17 步进 + A4988/TMC2209
- 语音：ASR（FunASR/Whisper）→ LLM API → TTS；唤醒用 openWakeWord
- 代码仓库：GitHub（开源，build in public），README 中英双语

## 7. 里程碑

| # | 里程碑 | 验收标准 |
|---|---|---|
| M1 | Blender 全套资产 | 核心球三视图+爆炸图；五载体模型；家族合影渲染；30s 概念片分镜 |
| M2 | 单轴滑台吊球走位 | 球沿单轴滑台走三点，到位亮灯 |
| M3 | 语音对话闭环 | 唤醒→问答→TTS 出声，全程 <3s 响应 |
| M4 | 双轴轨道 + 取放检测 | MVP 完整闭环，拍摄 demo 视频 |
| M5 | build in public 发布 | 视频+文章发小红书/B站/即刻； outreach 邮件发给 Skyris |

## 8. Blender 资产清单（M1 交付物）

1. 核心球：外壳双半球分件、灯带槽、内部环形支架、对接环；真实比例 12–15cm
2. 载体简化模型：轨道（铝型材+滑车）、飞猫（四角绞盘+细线）、简版机械臂、简版轮式底盘、简版四足（背部同规格对接环）
3. 渲染图：三视图 ×1、爆炸图 ×1、轨道形态效果图 ×1、家族合影 ×1
4. 表情材质 ×3：豆豆眼 / 眯眼 / 爱心眼（自发光，Eevee + Bloom）
5. 概念片分镜脚本（15–30s）：轨道滑出 → 缆绳吊起穿越房间 → 落上四足出门

## 9. 风险与边界

- 版权：不使用 NoNo 名称、蓝色涂装、平衡翼等独有表达；项目内不出现淘米素材
- 开源策略：代码/文档默认开源；如后期为对接接口申请实用新型，须先递交再公开结构细节
- 对接接口（机械+供电+数据）是长期核心资产，MVP 阶段只做"磁吸放置级"对接，但接口尺寸与引脚定义必须从此刻起冻结管理
