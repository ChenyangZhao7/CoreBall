# CoreBall 接口标准 · 设计文档

> 状态：已批准（2026-11-19） · 日期：2026-11-17 · 目标版本：接口标准 v1.1（v1.0 冻结后硬化）
> 本文是设计文档。批准后据此产出正式标准（`docs/04-接口标准.md` + 接口图）。

---

## 1. 一句话

球身上两个井，**同一套**：井径 30、深 5、6 个触点位、3 个不等距键位；头上的载体只焊 4 片，脚下的载体焊满 6 片。两根数据线用串口说话，载体插上就自报家门。

---

## 2. 为什么现在冻结

规格书原话：**「接口尺寸与引脚定义必须从此刻起冻结管理。」**

它是唯一一个后面所有零件都挂在上面、越晚改越贵的东西：球壳、吊点、五个载体、PCB、固件、线束全都依赖它。现在只有渲染图，改一次是改参数；等开模、等 PCB 打样之后，改一次是重做。

## 3. 目标

- 一张接口图 + 一张引脚表，任何人照着能做出兼容件。
- 头顶和脚底**机械上完全一致**（同一井径、同一键位、同一触点）；顶部载体与底部载体用互为镜像的插头零件，各自插自己那一头都能通电、能说话。同一个插头翻过来插另一头**不保证**能进——这是「离散键位 + 防插反」的代价，见 §9。
- 载体能向球「自我介绍」（几个轴、什么传感器、多大电流、叫什么）。
- 机械包络永不改；协议可以升版而不动物理件。

## 4. 非目标

- 不追求大带宽（不传图、不传音频）。
- 不做无线充电、不做电池热插拔。
- 不做多设备菊花链：**一个井只接一个载体**。
- 不解决「球在载体上自由旋转」——见 §6.7 的代价。

## 5. 反目标

- ❌ 不出现第二种接口家族（没有「轮式专用口」这种东西）。
- ❌ 球身上不出现任何凸出物（触点、磁铁、键全在载体一侧或齐平）。
- ❌ 不用电阻 ID 代替通信（头顶要控制偏航和伸缩，单向报名字不够）。
- ❌ 不在接口上走 USB。

## 7. 方案对比（已由你选定）

### 7.1 两个井的关系

| 方案 | 内容 | 取舍 | 结论 |
|---|---|---|---|
| **一套一档（选定）** | 两井都 φ30、6 触点位；头顶只焊 4 片 | 只有一种井、一张图；顶部与底部插头互为镜像；头顶井 +4 mm | ✅ |
| 一套两档 | 顶 φ26/4 针，底 φ30/6 针，键位共用 | 头顶保持小巧；但要记两个尺寸、两套零件 | ❌ |
| 两套独立 | 两头各定各的 | 各自最优；两套文档、两套库存 | ❌ |

选它的理由：最符合「一个灵魂、任意身体」，且「越晚定越贵」的东西只冻结一次。

### 7.2 数据线

| 方案 | 取舍 | 结论 |
|---|---|---|
| **UART（选定）** | 一对一、抗插拔、不怕总线锁死；4 根线刚好 | ✅ |
| I2C | 省线、可挂多设备；热插拔易锁死，要保护芯片 | ❌ |
| USB | 带宽大；球要当主机、枚举慢、触点一抖就掉 | ❌ |

选它的理由：头顶要控制吊点的偏航和伸缩，必须双向；而「自我介绍」天然是一段话，串口最合适。

## 8. 标准正文

### 8.1 包络（永不变）

```
                    剖面（过球心轴）
                          球壳
                      ╭─────────╮
                      │         │
                      │  ┌───┐  │
                      │  │   │  │  ← 井：φ30.00，深 5.0
                      │  │   │  │
                      │  └───┘  │
                      ╰─────────╯

   井口倒角 0.8 × 45°    井壁直    井底平面度 0.05
```

| 项 | 值 | 公差 |
|---|---|---|
| 井径 | φ30.00 | H8（+0.033 / 0） |
| 井深 | 5.00 | ±0.10 |
| 井底平面度 | — | 0.05 |
| 井壁与球心轴同轴度 | — | φ0.10 |
| 井口倒角 | 0.8 × 45° | — |
| 井环材质 | 6061 整体井杯，壁厚 0.8（井底、井壁、键槽、钢片窝一件） | — |

> 井深 5.00 的基准是**球顶切平面**（球坐标系 z = +40 / −40），不是球面与井壁的交线。球面在井口处的实际高度为 √(40²−15²) ≈ 37.08，因此井壁圆柱段只有约 2.1 mm；插头端面停在井底上方 0.4，露出球面约 2.9 mm 是设计姿态，不是装配错误。

| 项 | 值 | 公差 |
|---|---|---|
| 插头直径 | φ29.60 | ±0.05 |
| 插头高度 | 4.60 | ±0.05 |
| 径向总间隙 | 0.40（单边 0.20） | 0.30–0.50 |
| 插入力 | ≤ 25 N（含磁吸） | — |
| 侧向保持力 | ≥ 8 N | — |
| 插拔寿命 | ≥ 5 000 次 | — |

### 8.2 键位（防插反）

三个键，**间距不等**（96° / 128° / 136°），因此只有一种插入角度。两个井的键位在**同一球坐标系**里完全相同；因为从球的两头看过去互为镜像，顶部载体与底部载体要用**互为镜像的插头零件**——同一个插头翻过来插不进另一头。

| 项 | 值 |
|---|---|
| 键数量 | 3 |
| 键角度（0° = +X，从 +Z 看逆时针；两个井用**同一球坐标系**，不从井口翻转视角） | 0° / 96° / 224° |
| 键半径 | 12.6 mm |
| 键宽 × 径向长 × 高 | 3.0 × 3.0 × 2.0 mm（2.0 槽深 + 0.4 间隙 − 0.4 公差余量） |
| 键槽宽 × 径向长 | 3.4 × 3.4 mm（+0.4） |
| 键槽深 | 2.0 mm |
| 键在哪一侧 | **载体插头上（凸）**；球井底开槽（凹） |

> 模型现状与此相反（`if_key` 画在球井底上）。按设计决定 09「球永远是母座」，改为键在插头上。

### 8.3 触点

六个触点位，60° 均布；**头顶载体只用前四个**（因为滑环只有 4 路）。

| 项 | 值 |
|---|---|
| 触点角度（0° = +X，逆时针） | 0° / 60° / 120° / 180° / 240° / 300° |
| 触点半径 | 9.0 mm |
| 球侧焊盘 | 平焊盘 φ2.5，齐平井底 |
| 焊盘镀层 | Ni 3 µm + 硬金 1 µm，Ra ≤ 0.4 |
| 载体侧 | 弹簧针（pogo），针筒 φ1.5，行程 2.0，工作压缩 0.8 |
| 单针压力 | 0.8–1.2 N |
| 单针额定电流 | 2 A |
| 接触电阻 | ≤ 30 mΩ / 对 |
| 插拔顺序 | GND 针 +0.5 mm 最长 → TX/RX 齐平 → 5V 针 −0.5 mm 最短 |

> 先接地、后上电，避免带电插拔打火。

### 8.4 引脚定义

角度一律用**球的坐标系**：0° = +X，从 +Z 看逆时针为正；两个井都按这个坐标系量，不要从井口翻视角。TX/RX 一律以**球**为视角命名。

| # | 角度 | 功能 | 头顶（吊点） | 脚底（载体） |
|---|---|---|---|---|
| 1 | 0° | VBUS 5 V | ● | ● |
| 2 | 60° | GND | ● | ● |
| 3 | 120° | TX（球 → 载体） | ● | ● |
| 4 | 180° | RX（载体 → 球） | ● | ● |
| 5 | 240° | VBUS 5 V（并联） | — | ● |
| 6 | 300° | GND（并联） | — | ● |

- 4 片版 = 位置 1–4，正好对上吊点的四路滑环。
- 6 片版 = 位置 1–6，两路电源并联，承担 3 A。
- 位置 5/6 在 5 片以下的载体上**不焊接、不短接**。

### 8.5 磁吸

| 项 | 值 |
|---|---|
| 磁铁在哪一侧 | **载体插头上**（球侧只放钢片） |
| 球侧 | 3 × 430 钢片 φ6 × 1.0，齐平井底（不能用 304，冷加工后可能弱磁） |
| 载体侧 | 3 × N42 NdFeB φ6 × 2.5 |
| 磁铁角度 | 30° / 150° / 270°（避开键位；与键位同为球坐标系） |
| 磁铁半径 | 10.0 mm |
| 目标脱开力 | 12 ± 2 N（0.4 气隙；用 0.2 mm 非导磁垫片微调） |
| 摩擦环 | 硅胶 O 圈，中心线 r = 14.75，线径 0.8（自由外径 15.15，对 φ30 井壁单边过盈 0.15），坐在插头鼻子的环槽里 |

> 球侧不放磁铁，是为了「随手拿走」时不吸附桌面上的剪刀、尺子、钥匙。

### 8.6 供电

| 项 | 头顶 | 脚底 |
|---|---|---|
| 电压 | 5.0 V ±5%（4.75–5.25） | 同左 |
| 连续电流 | 0.4 A（≈2 W） | 3.0 A（≈15 W） |
| 峰值 | 0.6 A / 100 ms | 4.0 A / 500 ms |
| 纹波 | ≤ 100 mVpp | 同左 |
| 上电斜率 | 载体侧软启动，浪涌 < 2 A / 10 ms | 同左 |
| 方向 | 载体 → 球（球只受电，不回灌） | 同左 |

- 球侧 VBUS 串联理想二极管（P-MOS），**反接 −5 V 不损坏**。
- 球侧 VBUS 对地 100 µF + 软启动。
- 触点 ESD：接触放电 ±8 kV。
- 脚底 3 A 中预留 0.5 A 给球内缓冲电池充电。

### 8.7 串口

| 项 | 值 |
|---|---|
| 电平 | 3.3 V LVCMOS（载体 RX 需容忍 3.3 V） |
| 参数 | 115200 8N1，无流控 |
| 主从 | 球为主，载体为从 |
| 帧格式 | `A5 5A · VER(1) · TYPE(1) · LEN(1) · PAYLOAD(≤64) · CRC16-CCITT` |
| CRC | CRC-16/CCITT-FALSE：poly 0x1021，init 0xFFFF，不反射，xorout 0x0000；覆盖 `VER` 到 `PAYLOAD`（不含 `A5 5A`） |
| LEN | 只计 PAYLOAD 字节数（0–64） |
| WHO 请求 | `A5 5A · 10 · 01 · 00 · CRC`（TYPE=0x01，LEN=0） |
| 类型 | 0x01 WHO / 0x02 CMD / 0x03 STATUS / 0x04 HEARTBEAT / 0x05 ERROR |
| 上电握手 | 球每 100 ms 发 WHO 请求，最多 1 s |
| 无应答 | 300 ms 无 WHO 应答 → 判为「哑载体」，只供电、不下发动作 |
| 心跳 | 双向 200 ms；连丢 3 次 → 载体就地安全停止 |

**WHO 载荷（载体自述）**

| 字段 | 类型 | 说明 |
|---|---|---|
| proto | u8 | 协议版本，v1 = 0x10（高 4 位主版本） |
| class | u8 | 1 吊点 / 2 轨道 / 3 轮式 / 4 机械臂 / 5 四足 / 6 哑载体 |
| axes | u8 | 可控轴数 |
| sensors | u32 位图 | bit0 IMU / 1 里程计 / 2 ToF / 3 深度 / 4 相机 / 5 麦 / 6 电池 |
| draw_mA | u16 | 本载体需要的电流（mA）；超过本端能力则只供电、不动作 |
| battery_mAh | u16 | 自带电池容量，无则 0 |
| vmax | u16 | 最大速度（µm/s 或 mdeg/s，按轴） |
| name | UTF-8 ≤ 24 | 例如「轮式底盘 · 厨房那只」 |

**CMD 载荷**：`axis(u8) · target(i32, µm 或 mdeg) · vmax(u16) · amax(u16)`
**STATUS 载荷**：`pos(i32) · vel(i16) · fault(u16)`，1–50 Hz 按需。

### 8.8 版本管理

- 本文冻结为 **v1.0**。
- **机械包络（井径、井深、键位角度、触点角度与半径）永久冻结**。任何改动必须换新键位，使旧插头物理上插不进去——不允许「看起来一样但电气不同」。
- 协议可升小版本，只许加字段不许改语义；主版本不同 → 只供电。
- 每次改动在标准文档末尾的变更表记一行：版本 / 日期 / 改了什么 / 为什么 / 影响哪些件。

## 9. 这条标准带来的一个硬约束（必须提前知道）

**键位把球的朝向锁死了。** 球脸朝 +Y，键在 0°/96°/224°，于是球插上任何载体，脸的朝向相对载体是固定的。

推论：
- 吊点有 360° 偏航 → 没问题。
- 轮式底盘能自己转 → 没问题。
- **桌面轨道滑车不能转** → 它要么按「脸朝乘客」固定安装，要么自己在滑车上再加一个偏航关节，并在自述里报 `axes = 2`（轨道 + 偏航）。

这是选「离散触点 + 防插反键」换来的代价。想自由旋转就得用同心环触点，成本和磨损都上一个台阶，本期不做。

## 13. 我在写这份文档时替你做的决定（请逐条看，不同意就划掉）

1. **磁铁在载体侧、钢片在球侧**——避免球吸附桌面杂物。
2. **6 个触点里 2 个是电源并联**——3 A 单针太勉强。
3. **磁铁偏离键位 30°**——避免和键、触点撞在一起（已核算间距）。
4. **插拔顺序 GND 先、5V 后**——防打火。
5. **键在插头、槽在球上**——兑现「球永远是母座」。
6. **球侧加理想二极管**——反接不烧。
7. **摩擦环用硅胶 O 圈**——比机械卡扣便宜，且不增加凸起。
8. **无应答 300 ms 判为哑载体**——让没有 MCU 的简单载体也能用。
