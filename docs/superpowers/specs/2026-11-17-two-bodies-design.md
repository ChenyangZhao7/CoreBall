# 一个核心，两个身体 · 设计（短）

> 日期：2026-11-17 · 状态：待批准 · 类型：一个子系统（灵魂可移植性）

## 要证明什么

**同一个核心，接上吊索是飞猫，接上小机器人是地面伴；换身体时，记忆和当前目标都不丢。**

不是外观，是四个契约里的三条：能力协商、意图抽象、连续性。感知上交和安全归属留到下一步。

## 两个身体

| | 吊索（已有） | 小机器人（新建） |
|---|---|---|
| 运动 | 三维 | 地面二维 + 朝向 |
| 球的可见性 | 露在外面 | **完全在体内，看不见** |
| 「过来」实现成 | 飞到侧位 `(-380,520,1300)` | 开到人椅子前方 `(-380,520,0)` |
| 「看我」实现成 | 转脸 | 原地转车身 |
| 「升/降」 | 真的有 | **做不到 → 拒绝，并说明** |
| 描述 | class 1，3 轴，有线 | class 3，2 轴，有线 |

最后一行是这设计的眼睛：**同一个意图，在新身体上可以做不到**。核心必须接受「这个身体没有这个自由度」，而不是假装动了。

## 换身

一条控制意图：

```json
{"intent": "mount", "body": "rover"}
```

- 卸下：吊索上的球消失，吊点收拢。
- 装上：机器人底盘的「核心灯」亮起（球在里面，看不见）。
- **交接当前目标**：如果核心正在执行「过来」，新身体从它的起点继续表达这个目标。

## 连续性

| 东西 | 存哪 | 换身后 |
|---|---|---|
| 对话记忆 | `memory/events.jsonl` | 不变 |
| 当前目标 | `memory/state.json` | 交给新身体重新表达 |
| 人格 | `persona.md` | 不变 |
| 身体模型 | 运行时按描述重建 | 换 |

## 演示脚本（这就是验收）

1. `我来晚了` → 吊索上的球从待命位移到侧位。
2. `换到车上` → 吊索的球消失，地面小车亮起。
3. `过来` → 小车开到椅子前；**注意它走的是地面，不是空中**。
4. `升起来` → 它说「这个身体没有升降」，**不动**。
5. `换回吊索` → 小车熄灯，吊索上的球出现，仍在刚才的位置。
6. `我刚才让你干什么` → 它记得第 3 步的「过来」。

## 文件

```
blender/build_command.py     加一个小机器人模型（车身 + 两轮 + 万向轮 + 核心灯）
blender/cmd_runtime.py       两个身体的 apply()、mount 切换、目标交接
body.py                      身体描述与意图映射（纯函数，可测）
brain.py                     state.json（当前目标）+ --mount 命令
tools/test_body.py           纯函数测试
blender/tests/test_bodies.py 场景测试（两个身体都在、切换生效）
```

## 非目标

- 不做感知上交（身体传感器变成核心感官）。
- 不做安全归属（车身自己的避障）。
- 不做真机。
- 不做换身动画（直接切换 + 灯光变化）。

## 完成的标准

1. `python tools/test_body.py` 与 Blender 无头测试全绿。
2. 六个演示步骤能在 Blender 里按顺序走通。
3. 换身后 `memory/state.json` 里的目标还在，新身体接着执行。
4. 「升起来」在小机器人上被明确拒绝，而不是静默失败。
