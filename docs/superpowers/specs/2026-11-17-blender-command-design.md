# 三维指挥 · Blender 交互场景 · 设计（短）

> 日期：2026-11-17 · 状态：待批准 · 类型：小改动（Blender 脚本 + 一个场景文件）
> 取代：`2026-11-17-3d-command-demo-design.md`（网页方案，已废弃）

## 一句话

打开 Blender，**直接拖动一个控制点**，球和吊点跟着走，四根线实时重算并在角上写出线长和张力；拖进禁区会被弹回边界。

## 为什么

- 你要的是「在三维空间里灵活指挥」，而 Blender 已经装着全部真实模型和真实坐标——不需要再造一套前端。
- 拖动比渲染视频更能说明「可指挥」；也比网页省掉一整套技术栈。
- 场景里的数字必须和 `tools/tension.py` 一致，否则它只是动画，不是模型。

## 目标

1. 双击 `blender/指挥.bat`，直接进入指挥场景。
2. 拖动 `CMD_TARGET`，球、吊点、四根承力线、第五根供电线**实时**跟随（Blender 原生 Hook，不加插件）。
3. 相机视角角上有一块文字面板：球坐标、四根线长、四根张力、最松余量、状态。
4. 拖进脖子禁区（r210 圆柱）→ 自动弹回边界，面板写「安全层否决」。
5. 拖到线绷不住的地方（最松 < 0.3 N）→ 面板变红，写「力封闭失效」。
6. 在场景里随便转视角、进相机视角、拉近看，线和球不穿帮。

## 非目标

- 不做物理摆动、不做绳子下垂（线是直的）。
- 不做滚筒转动、不做电机联动。
- 不做导出视频（下一步可以加）。
- 不做偏航/伸缩动画（吊点保持刚性）。

## 反目标

- ❌ 不引入网页、前端框架、任何外部依赖。
- ❌ 不复制一份球/吊点的模型——直接复用 `coreball_rig.blend` 里的对象。
- ❌ 不靠手抄数字：线长和张力必须由 `tools/tension.py` 现场算。

## 场景结构（全部用现有真实数字）

| 对象 | 内容 |
|---|---|
| `CMD_TARGET` | 新建空物体，球心，默认 `(-380,520,1300)`，显示成可抓的球 |
| `ball_root` | 现有空物体，父级改为 `CMD_TARGET` |
| `HUB_ROOT` | 新建空物体，在球心上方 160 mm；`04_吊点` 全部对象父级改为它；它父级为 `CMD_TARGET` |
| `cable_1..4` | 现有曲线；末端 Hook 到 `lug_1..4` |
| `wire_1/2` | 现有供电线；滑轮那一端 Hook 到 `tether_sheave` |
| `HUD` | 新建文字物体，父级为相机，相机视角左上角 |
| 相机 | 沿用 rig 里的相机 |

## 怎么“指挥”

Blender 原生操作，不写界面：

- 选中 `CMD_TARGET`，按 `G` 拖动，或直接拖它的 gizmo。
- 鼠标中键转视角，滚轮缩放，`Numpad 0` 进相机视角。
- 面板不是按钮，只读。

## 运行方式（重要）

Blender 默认关闭「自动运行 Python」，所以面板刷新和禁区回弹**不能**靠 .blend 自带脚本：

- `指挥.bat` 用 `blender <blend> --python cmd_runtime.py` 启动，handler 随之注册。
- **如果直接双击 .blend**：Hook 仍然生效（线和球照样跟随），但面板不刷新、禁区不拦。这是可接受的降级。

## 文件

```
blender/build_command.py     新建：从 coreball_rig.blend 生成指挥场景
blender/cmd_runtime.py       新建：启动时注册面板刷新 + 禁区回弹
blender/指挥.bat             新建：一键启动
blender/tests/test_command.py  新建：无头验收（用 Blender 跑）
blender/out/cmd/coreball_command.blend  产物
README.md                    目录里加一行
```

## 完成标准

1. 拖 `CMD_TARGET` 三个轴各 200 mm，四根线端点始终贴住 `lug_1..4`（误差 < 0.5 mm）。
2. 默认位面板显示：`555 / 1210 / 481 / 1071 mm`、`3.69 / 2.05 / 2.76 / 2.05 N`、最松 `2.05 N`
   （按吊点 `-380, 520, 1460` 算；四根线挂在吊点挂耳上，不按球心算）。
3. 拖到 `(-700,300,1150)`：面板变红写「力封闭失效（最松 0.17 N）」。
4. 拖到 `(0,890,1300)`：目标自动弹到 `(210,890,1300)`，面板写「安全层否决」。
5. 拖动时视口可交互（不卡死）。
6. 无头测试：`blender --background --python blender/tests/test_command.py` 输出 `PASS`。
